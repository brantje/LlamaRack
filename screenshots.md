# LlamaRack screenshots

These screenshots were generated from the project's existing Playwright UI screenshot suite using the `desktop-wide-1920x1080` project.

All images in [`screenshots/`](screenshots/) are normalized to an exact **1920×1080** frame. The UI fixtures and mocked API states come from the repository's E2E screenshot tests, so the gallery covers normal, empty, loading, confirmation, and failure states without requiring a live inference backend.
